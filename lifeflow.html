LifeFlow

A Python library that brings life insurance actuarial calculations from Excel into code: easy to reproduce, fully auditable and ready to run on their own. Less manual work, fewer errors, results you can trust.

See the examples → GitHub · coming soon

The problem it solves

From Excel to code, without losing control.

In many teams, the valuation of a life portfolio lives inside a spreadsheet: powerful to get started, but hard to audit, hard to repeat without mistakes and hard to scale. Every closing means repeating manual steps and trusting tangled formulas that only one person really understands.

LifeFlow is a set of functions designed to move that calculation into Python in a direct way. You take what the spreadsheet does over the portfolio and reproduce it in code; from there the process becomes automated, versioned and ready to run as many times as needed, with full traceability.

Practical examples

Illustrative snippets — the final API may still change.

1 · Quick start

import lifeflow as lf

# Load a standard mortality table and a policy portfolio
table     = lf.MortalityTable.load("PERM_2020")
portfolio = lf.read_portfolio("life_portfolio.xlsx")

# Value the whole book under IFRS 4 and export the result
reserves = lf.reserves(portfolio, table, basis="IFRS4", interest=0.02)
reserves.to_excel("reserves_2026.xlsx")

2 · Survival & death probabilities

# Straight from the mortality table
table.p(x=45, t=10)          # 10-year survival probability, age 45  → 0.9721
table.q(x=45)                # 1-year death probability (mortality rate)  → 0.00187
table.life_expectancy(x=65)  # curtate life expectancy e_x  → 21.4

3 · Actuarial present values

# Price a whole-life annuity-due and a 20-year term insurance
annuity = lf.annuity_due(age=65, table=table, interest=0.02)      # ä_x
term    = lf.term_insurance(age=40, n=20, table=table, i=0.02)    # A¹_(x:n)

print(f"Annuity factor  a-due(65) = {annuity:.4f}")   # 16.3820
print(f"Term insurance  A(40:20)  = {term:.5f}")       # 0.03145

4 · Reserve projection (the "flow")

# Project mathematical reserves year by year for one policy
policy   = portfolio.get("POL-00042")
schedule = lf.project_reserves(policy, table, years=range(2026, 2031))

print(schedule)
#   year    reserve   premium   benefit_outgo
#   2026    1240.55    480.00      0.00
#   2027    1690.12    480.00      0.00
#   2028    2151.40    480.00      0.00
#   2029    2624.88    480.00      0.00
#   2030    3110.97    480.00      0.00
